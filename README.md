## 🌟 Overview

**KlarBerlin** is an experimental creative web experience inspired by contemporary European fashion and design studios. It combines minimalist editorial typography with interactive WebGL post-processing shaders, mouse-driven parallax, and smooth transition mechanics.

- 🔗 **Live Demo:** [https://klarberlin.vercel.app](https://klarberlin.vercel.app)
- 👤 **Author:** [Erum Khan (@erum-dev-max)](https://github.com/erum-dev-max)

---

## 🚀 Key Features

- 🎨 **Editorial Layout & Design:** High-contrast aesthetic with generous whitespace and bold typography.
- 🌀 **Custom WebGL Shaders:** Interactive canvas distortion and texture sampling responding to user cursor momentum.
- ⚡ **Silky Navigation & Scroll:** Precision easing and decoupled scroll state for zero jank.
- 📱 **Adaptive UI:** Thoughtfully tailored for mobile, tablet, and ultra-wide monitor viewing.

---

## 🛠️ Tech Stack

- **Frontend & Logic:** TypeScript, HTML5, Modern CSS
- **Graphics & Animation:** WebGL, Three.js, Custom Shaders
- **Tooling:** Vite
